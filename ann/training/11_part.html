Variants of Training in Deep Learning#

Motivation#

Deep learning models are not trained using a single universal strategy. Different training variants exist to address:

  • Data size and distribution

  • Hardware constraints

  • Optimization stability

  • Generalization requirements

  • Real-time deployment needs

These variants shape how data flows, how gradients are computed, and how models evolve over time.

Core Training Paradigms#

Variant

Purpose

Mini-Batch Training

Batch, Mini-Batch, and Stochastic Training#

Batch Gradient Descent#

  • Entire dataset used for each update

  • Very stable, very slow

  • Rarely used in practice

for X, y in [(X_all, y_all)]:
    loss = criterion(model(X), y)
    loss.backward()
    optimizer.step()

Stochastic Gradient Descent#

  • One sample per update

  • High variance, unstable

loader = DataLoader(dataset, batch_size=1, shuffle=True)

Mini-Batch Gradient Descent (Standard)#

  • Balance between stability and efficiency

loader = DataLoader(dataset, batch_size=32, shuffle=True)

Transfer Learning#

Reuse pretrained representations.

model = torchvision.models.resnet18(pretrained=True)
for param in model.parameters():
    param.requires_grad = False

model.fc = nn.Linear(512, num_classes)

Fine-Tuning#

Gradually unfreeze layers.

for param in model.layer4.parameters():
    param.requires_grad = True

Online / Continual Training#

Model updated as data arrives.

for X, y in data_stream:
    loss = criterion(model(X), y)
    loss.backward()
    optimizer.step()

Multi-Stage / Curriculum Training#

Train on easier data first.

Stage

Dataset

1

Clean, small

2

Larger, noisier

3

Full-scale data

Self-Supervised Training#

No labels; model learns structure.

loss = contrastive_loss(encoder(x1), encoder(x2))

Distributed Training#

Scale across GPUs.

model = torch.nn.parallel.DistributedDataParallel(model)

Mixed Precision Training#

Reduces memory and increases speed.

scaler = torch.cuda.amp.GradScaler()

with torch.cuda.amp.autocast():
    loss = criterion(model(X), y)

scaler.scale(loss).backward()
scaler.step(optimizer)
scaler.update()

Training Strategy Selection#

Scenario

Strategy

Small dataset

Transfer learning

Massive dataset

Distributed training

Limited GPU memory

Mixed precision

Streaming data

Online training

High overfitting

Curriculum + fine-tuning

Key Insight#

Training is not a single algorithm — it is a system design problem combining optimization, data management, and generalization control.
