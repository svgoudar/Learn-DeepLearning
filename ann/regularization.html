Regularization#

Concept and Motivation#

Regularization is a family of techniques that improve a model’s generalization by discouraging overly complex solutions that fit training data too closely.

From a learning theory perspective, regularization controls the effective capacity of the model:

  • Too much capacity → overfitting

  • Too little capacity → underfitting

  • Proper regularization → bias–variance trade-off

Intuition#

A neural network learns a function \(f_\theta(x)\). Regularization modifies the training objective:

\[ \min_\theta ; \mathcal{L}(\theta) + \lambda \cdot \Omega(\theta) \]

  • \(\mathcal{L}(\theta)\): data loss

  • \(\Omega(\theta)\): complexity penalty

  • \(\lambda\): regularization strength

The optimizer now prefers simpler parameterizations that explain the data.

Workflow Integration#

Training Pipeline with Regularization

Data → Model → Loss + Regularization → Backprop → Update → Validation

Practical steps

  1. Choose base model

  2. Add explicit regularizers (L1/L2, Dropout)

  3. Train while monitoring validation loss

  4. Apply early stopping

  5. Tune λ via validation

PyTorch Demonstration#

Baseline Model#

import torch
import torch.nn as nn

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(20, 128),
            nn.ReLU(),
            nn.Linear(128, 1)
        )

    def forward(self, x):
        return self.net(x)

L2 Regularization (Weight Decay)#

model = Net()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3, weight_decay=1e-4)

weight_decay implements L2 penalty.

Dropout Regularization#

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(20, 128),
            nn.ReLU(),
            nn.Dropout(p=0.5),
            nn.Linear(128, 1)
        )

    def forward(self, x):
        return self.net(x)

During training, neurons are randomly removed; during inference, full network is used.

Early Stopping Logic#

best_val = float('inf')
patience, wait = 5, 0

for epoch in range(100):
    train()
    val_loss = validate()

    if val_loss < best_val:
        best_val = val_loss
        wait = 0
    else:
        wait += 1
        if wait == patience:
            break
