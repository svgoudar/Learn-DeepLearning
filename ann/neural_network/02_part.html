Neural Network House Price Prediction#

Problem Statement: House Price Prediction#

We want to build a neural network that predicts the market price of a house based on measurable features.

Inputs (Features)#

Feature

Symbol

Description

Living Area

\(x_1\)

Square footage

Bedrooms

\(x_2\)

Number of bedrooms

Bathrooms

\(x_3\)

Number of bathrooms

Age

\(x_4\)

Years since construction

Location Score

\(x_5\)

Quality of location (1–10)

Output#

\[ y = \text{House Price} \]

This is a supervised regression problem: $\( f_\theta(x_1, x_2, ..., x_5) \approx y \)$

where \(\theta\) are trainable parameters.

Neuron: Deep Learning Perspective (Intuition)#

A neuron models a small decision unit that learns:

How important is each feature, and how should they combine to estimate price?

Mathematical Form of One Neuron#

\[ z = w_1x_1 + w_2x_2 + ... + w_5x_5 + b \]
\[ a = \phi(z) \]

Where:

  • \(w_i\): learned importance of feature \(x_i\)

  • \(b\): bias (baseline price offset)

  • \(\phi\): activation function

  • \(a\): neuron output

Economic Interpretation#

Component

Meaning in House Pricing

\(w_1\)

Price increase per square foot

\(w_2\)

Added value of a bedroom

\(b\)

Base land value

\(\phi\)

Market nonlinearity (e.g., diminishing returns)

A neural network stacks many such neurons to learn complex market behavior.

Neural Network Architecture for the Task#

[Area, Beds, Baths, Age, Location]
              ↓
          Linear Neurons
              ↓
         Nonlinear Hidden Layers
              ↓
           Price Output

Learning Workflow#

  1. Forward pass: predict price

  2. Compute error: $\( \mathcal{L} = | \hat{y} - y |^2 \)$

  3. Backpropagation: compute gradients

  4. Update weights with gradient descent

  5. Repeat until convergence

PyTorch Implementation#

Dataset (Synthetic)#

import torch
from torch import nn

X = torch.tensor([
    [1200, 3, 2, 10, 7],
    [800, 2, 1, 20, 5],
    [1500, 4, 3, 5, 9],
    [600, 1, 1, 30, 4]
], dtype=torch.float32)

y = torch.tensor([[300], [180], [420], [130]], dtype=torch.float32)

Model Definition#

class HouseNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(5, 16),
            nn.ReLU(),
            nn.Linear(16, 8),
            nn.ReLU(),
            nn.Linear(8, 1))

    def forward(self, x):
        return self.net(x)

Training Loop#

model = HouseNet()
loss_fn = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

for epoch in range(1000):
    pred = model(X)
    loss = loss_fn(pred, y)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    if epoch % 200 == 0:
        print(f"Epoch {epoch}, Loss {loss.item():.4f}")

Inference#

new_house = torch.tensor([[1000, 3, 2, 8, 6]], dtype=torch.float32)
price = model(new_house)
print("Predicted price:", price.item())

Why Nonlinearity Matters#

Without activations, the model is only linear: $\( f(x) = Wx + b \)$

With neurons + nonlinearities:

  • Captures market interactions

  • Models diminishing returns

  • Learns feature coupling (e.g., large house in bad location ≠ expensive)
