Choice of Loss Function#

When designing a neural network, the choice of activation function in the output layer directly determines which loss function you should use. The hidden layers usually use ReLU or its variants.

Binary Classification#

Setup:

  • Hidden layers: ReLU

  • Output layer: Sigmoid

Reason: Sigmoid outputs a probability between 0 and 1 for two classes.

Loss Function:

  • Binary Cross Entropy (BCE)

Example: Spam detection, yes/no classification

Multi-class Classification#

Setup:

  • Hidden layers: ReLU

  • Output layer: Softmax

Reason: Softmax outputs probabilities across multiple classes that sum to 1.

Loss Function:

  • Categorical Cross Entropy (CCE) if labels are one-hot encoded

  • Sparse Categorical Cross Entropy if labels are integers

Example: Digit recognition (0–9), sentiment analysis with multiple classes

Regression#

Setup:

  • Hidden layers: ReLU (or variants like Leaky ReLU, PReLU, ELU)

  • Output layer: Linear

Reason: Linear activation allows the output to take any continuous value.

Loss Functions:

  • Mean Squared Error (MSE)

  • Mean Absolute Error (MAE)

  • Huber Loss

  • Root Mean Squared Error (RMSE)

Example: Predicting house prices, stock prices

Key Takeaways

  1. Output layer activation defines loss function:

    • Sigmoid → Binary Cross Entropy

    • Softmax → Categorical/Sparse Cross Entropy

    • Linear → MSE, MAE, Huber, RMSE

  2. Hidden layers usually use ReLU or its variants.

  3. Choosing the correct combination ensures:

    • Faster convergence

    • Correct gradient calculation

    • Efficient training

This ensures your loss decreases properly during training and your network learns efficiently.
